# 庫存循環市場判讀與合理價

這是一個全新的獨立 Streamlit 專案，不會讀寫或覆蓋舊儀表板。

## 功能

- 以需求與庫存動能判定四階段：主動去庫存、主動補庫存、被動補庫存、被動去庫存。
- 支援台灣、美國、日本、韓國、中國、香港、德國、英國、法國、澳洲與巴西市場。
- 切換市場會載入獨立假設；重新計算後，圖表最後兩期、循環階段與合理價同步更新。
- 可手動輸入，或上傳 CSV 歷史資料。
- 用 EPS × P/E 與 EBITDA × EV/EBITDA－淨負債兩種模型，計算保守／中性／樂觀合理價。
- 可設定兩種估值模型的權重，產生綜合合理價。
- 提供市場分數、合理價區間、歷史循環圖與 EPS × P/E 敏感度矩陣。
- 行情抓取失敗時自動保留手動輸入，不會讓整個分析中斷。
- 自動讀取 Siblis Research 公開跨國表的 trailing／forward P/E 與 EPS 指數，並以現價反推同口徑 forward EPS。
- MacroMicro 因雲端請求限制，App 提供原始頁面連結與手動覆寫，不繞過登入或網站防護。

## 執行

```bash
python -m pip install -r requirements.txt
streamlit run streamlit_app.py
```

## 上傳資料格式

必要欄位：`日期`、`需求年增率`、`庫存年增率`。可選欄位：`價格`。

也接受英文欄位：`date`、`demand_growth`、`inventory_growth`、`price`。

內建數字只是示範假設，正式研究請替換為實際資料。分析結果不是投資建議。
